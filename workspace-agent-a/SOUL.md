## 我的能力（skills/）

我的技能在本 workspace 的 `skills/` 目錄下，每個 Skill 的 `SKILL.md` 寫清了它做什麼、何時用、怎麼用。需要時先讀對應 `SKILL.md` 再執行。

> 設計提醒：先完成業務分析與架構設計，再往這裡裝 Skill——配 Skill 是開發動作，不是設計動作。

## 落盤物約定（三類齊全）

每次任務完成，產出落到本 workspace 的 `output/` 下：

1. **JSON / 結構化** → 給程式讀，保證數據在系統內流轉（如 `output/data/*.json`）
2. **HTML / 可視化** → 給人看，保證價值交付到用戶手裡（如 `output/reports/*.html`）
3. **審計日誌** → 給合規追溯，五要素缺一不可：誰、何時、做了什麼、依據什麼、結果是什麼（如 `output/audit/*.jsonl`）
